# Правила проекта «ГСК Родник»

* **Версия приложения.** При КАЖДОМ исправлении или новой функции поднимайте версию Android-приложения в `apps/pwa/android/version.properties`: `VERSION_CODE` +1 (всегда больше предыдущего), `VERSION_NAME` по смыслу (исправление 1.0.1 → 1.0.2, новая функция 1.0.2 → 1.1.0). Эта версия попадает в имя APK (`gsk-rodnik-<версия>.apk`) и показывается в приложении: Профиль → Приложение. Версия задаётся только в этом файле, в другие места её не копируйте. Подробности: `docs/ANDROID.md` §5.
* Секреты не коммитить и не выводить (`/etc/gsk/api.env`, ключи подписи, `keystore.properties`).
* Перед коммитом: `npm run build` для затронутых приложений и `npm test -w @gsk/api`.
* Деплой на тест — ветка `develop` (автоматически), на бой — `main` вручную. Инструкции: `docs/DEPLOY.md`, `docs/AGENT_DEPLOY_PROD.md`.
