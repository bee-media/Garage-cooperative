# ГСК «Родник» — система управления гаражным кооперативом

Открытая система для гаражно-строительного кооператива (ГСК): учёт гаражей и владельцев, начисления и долги, показания электросчётчиков, новости правления, доска объявлений, карта территории, push-уведомления и мобильное приложение для жителей.

Проект создан для реального ГСК и работает на практике. Теперь он открыт для всех: берите, разворачивайте у себя, дорабатывайте под свой кооператив.

> 📄 **Презентация с картинками и описанием функций:** [docs/presentation/gsk-rodnik-presentation.pdf](docs/presentation/gsk-rodnik-presentation.pdf)

## Для чего это нужно

Председателю и правлению ГСК обычно приходится вести всё в таблицах, мессенджерах и на бумаге: кто сколько должен, кто передал показания счётчика, где объявления и новости. «Родник» собирает это в одном месте:

- жители видят свой долг, передают показания счётчика с фото, читают новости правления и подают объявления прямо с телефона;
- правление принимает платежи, проверяет показания, модерирует объявления, рассылает уведомления и видит всю картину на дашборде.

## Возможности

**Жители (мобильное приложение / PWA)**
- вход по номеру телефона, пароль выдаёт администратор;
- свои гаражи и текущий долг, push-напоминание должникам;
- передача показаний электросчётчика: значение, не менее 2 фото, комментарий;
- новости правления с поиском и закреплёнными записями;
- доска объявлений (продажа/аренда гаражей), до 5 фото, модерация перед публикацией;
- расписание работы правления и контакты;
- карта ГСК с цветом гаража по статусу долга;
- список своих устройств и выход со всех.

**Правление (веб-портал)**
- пользователи, роли и гранулярные права (матрица «роль × право» настраивается);
- гаражи, история владельцев, массовое создание, льготы;
- начисления: электроэнергия и членские взносы, частичные платежи, авансы, пени;
- квитанции (PDF, отправка на email, печать) с настраиваемым шаблоном;
- приём и проверка показаний счётчиков;
- публикация новостей, модерация объявлений с указанием причины отказа;
- редактор карты ГСК (ряды боксов, отметки вроде «нет света»);
- дашборд: долги по видам, должники, не сдавшие показания, очередь модерации;
- импорт и экспорт Excel;
- журнал аудита: все действия, «было → стало», IP и устройство, только добавление записей;
- загрузка новых версий Android-приложения прямо из портала.

## Безопасность

- пароли хранятся как argon2id; короткоживущие JWT и обновляемые refresh-токены с ротацией;
- у администраторов двухфакторная защита (TOTP), httpOnly-cookie и CSRF-защита;
- права проверяются на сервере, защита от IDOR, rate-limit, блокировка после 5 неверных попыток;
- загружаемые файлы проверяются по сигнатуре, из фото удаляются EXIF-данные;
- фото и файлы отдаются только авторизованным пользователям.

Подробности: [docs/SECURITY_REVIEW.md](docs/SECURITY_REVIEW.md). В репозитории нет ни паролей, ни ключей, ни токенов: все значения в `.env.example` и шаблонах — заглушки, свои секреты задайте сами.

## Мобильный клиент

Исходный код Android-приложения лежит в [apps/pwa/android](apps/pwa/android). Готовый APK в репозиторий не добавлен: приложение собирается под адрес **вашего** сервера и подписывается **вашим** ключом, а push-уведомления требуют вашего проекта Firebase. Пошаговая инструкция: [docs/ANDROID.md](docs/ANDROID.md). Версия приложения задаётся в `apps/pwa/android/version.properties`.

Для iPhone и любых других телефонов есть PWA: открывается в браузере и ставится «на экран».

## Быстрый старт для разработки

Нужны Node.js 22+ и PostgreSQL 16.

```bash
npm install
cp apps/api/.env.example apps/api/.env      # заполните секреты своими значениями
npm run db:migrate -w @gsk/api               # применить миграции
npm run db:seed -w @gsk/api                  # создать первого администратора
npm run start:dev -w @gsk/api                # API на :3000
npm run dev -w @gsk/admin                   # портал правления
npm run dev -w @gsk/pwa                     # приложение жителей
```

Тесты и сборка: `npm test -w @gsk/api`, `npm run build -w @gsk/<имя>`.

Развёртывание на сервер: [docs/DEPLOY.md](docs/DEPLOY.md). Техническое задание: [docs/SPEC.md](docs/SPEC.md). Импорт данных из Excel: [docs/DATA.md](docs/DATA.md).
