# Excel и квитанции

## Выгрузка (раздел «Данные (Excel)»)
Пять файлов: пользователи, гаражи и владельцы, задолженности (цвет статуса, итоговая строка), начисления и оплаты за период.
Даты в файлах — по московскому времени. Кнопки «Excel» есть также на страницах «Пользователи», «Гаражи», «Задолженности».
Права: `data.export` + право на просмотр соответствующего раздела. Каждая выгрузка пишется в журнал действий.

## Загрузка
Раздел «Данные (Excel)» → «Шаблон» (скачать пример с инструкцией) → «Загрузить».
Порядок: 1) гаражи и владельцы, 2) начисления / входящие долги, 3) оплаты.

* Файл сначала **проверяется**: показывается отчёт (сколько будет создано/обновлено) и ошибки по номерам строк. Записать данные можно, только когда ошибок нет.
* Названия колонок распознаются гибко («Телефон», «Тел.», «Мобильный»…), порядок колонок и лишние колонки не важны. Читается лист «Данные» (или первый лист).
* Телефон — в любом формате (+7 909 111-22-77, 89091112277). У одного гаража может быть несколько владельцев — несколько строк с одним номером.
* Новые пользователи создаются как «Жители» **без известного пароля**: пароль выдаёт председатель кнопкой «Выдать пароль» в карточке пользователя.
* Существующие записи не затираются: пустые поля дополняются. Галочка «Обновлять существующие» разрешает перезапись.
* Начисления/оплаты: повторная загрузка того же файла блокируется (защита от дублей); при необходимости — галочка «Всё равно загрузить повторно».
* Все загрузки видны в «Истории загрузок» и в журнале действий. Лимит: файл до 3 МБ, до 5000 строк.
* Права: `data.import` + право на сам вид данных (гаражи — `garages.edit` и `users.edit`; начисления — `charges.edit`; оплаты — `payments.edit`).

## Квитанции
* Шаблон: «Настройки» → «Квитанции и почта» (реквизиты, текст сверху/снизу, назначение платежа, подписант, QR). Кнопки «Образец» показывают результат.
* Квитанция на оплату — по карточке гаража (печать / на почту) и пакетом по должникам (страница «Задолженности»: общий PDF для печати и рассылка на почту).
* Чек об оплате — у каждой оплаты в карточке гаража; можно включить автоотправку при приёме оплаты.
* QR-код оплаты (ГОСТ Р 56042, ST00012) читается банковскими приложениями; сумма — текущий долг.
* Письма одному адресу группируются: владелец нескольких гаражей получает одно письмо с несколькими PDF. Перед массовой рассылкой показывается число адресатов.

## Почта
Переменные окружения API (`/etc/gsk/api.env`): `SMTP_HOST`, `SMTP_PORT` (587), `SMTP_SECURE` (`1` для порта 465), `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM`.
Для 587 по умолчанию используется STARTTLS, если сервер его предлагает; `SMTP_REQUIRE_TLS=1` требует шифрования обязательно.
Без `SMTP_HOST` включён **тестовый режим**: письма не уходят, а сохраняются как `.eml` в `storage/mail-outbox` — удобно на тестовом сервере.
Проверка: «Настройки» → «Отправка почты» → тестовое письмо. Последние письма и ошибки видны в таблице ниже.
После изменения env: `sudo systemctl restart gsk-api`.
На уже развёрнутых серверах `setup.sh` не перезаписывает `api.env` — добавьте строки `SMTP_*` вручную (образец — `apps/api/.env.example`).
После обновления роль «Бухгалтер» в уже работающей системе нужно дополнить правами «Экспорт/Импорт данных в Excel» в разделе «Роли и права» (роль «Председатель» получает их автоматически при деплое).
